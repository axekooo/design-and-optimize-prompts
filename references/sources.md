# Sources for General Prompt Design

Sources checked on September 27, 2026. This file records the origin of general ideas; it does not prescribe provider settings, model selection, or migration procedures. The workflow and templates are practical synthesis rather than verbatim requirements from any one source.

## Guides supplied by the user

- [OpenAI guide supplied by the user](https://developers.openai.com/api/docs/guides/latest-model): General ideas retained include clear completion criteria, focused clarification, consistent instructions, explicit writing preferences, and proportionate verification. Product capabilities, named-model observations, and migration settings are excluded.
- [Alibaba Cloud prompt engineering guide](https://help.aliyun.com/zh/model-studio/prompt-engineering-guide): Clarify context, purpose, audience, tone, and output; use boundaries, examples, and necessary steps to reduce ambiguity; iterate from observed results. The [original link](https://docs.modelstudio.console.alibabacloud.com/zh/model-studio/prompt-engineering-guide) exceeded retrieval limits, so the matching official help page was consulted.

## Supporting methods

- [OpenAI prompt engineering guide](https://developers.openai.com/api/docs/guides/prompt-engineering): Organize instructions and relevant context clearly and verify behavior through task examples.
- [OpenAI evaluation best practices](https://developers.openai.com/api/docs/guides/evaluation-best-practices): Use task-relevant cases, calibrate automated grading with human judgment, and account for position and verbosity bias in paired comparisons.

Use frameworks selectively. Examples, process steps, and execution rules should solve a demonstrated need rather than becoming mandatory decoration. Applying these general methods does not require a particular provider or hosted evaluation service.
